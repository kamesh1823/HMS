📡 PSNR

Peak Signal-to-Noise Ratio measures how much distortion the encryption introduced. Encrypted PSNR should be low (image destroyed). Decrypted PSNR should be high ≥35 dB (image restored).

Encrypted: <15 dB ✓   Decrypted: >35 dB ✓

🌀 SSIM

Structural Similarity Index measures how structurally similar two images are. Encrypted SSIM near 0 means the image structure is completely destroyed. Decrypted SSIM near 1 means the image is fully recovered.

Encrypted: <0.1 ✓   Decrypted: >0.95 ✓

📊 Entropy

Shannon entropy measures randomness of pixel values. A natural image has entropy 6–7 bits. A strongly encrypted image should have entropy close to 8.0, meaning pixel values are uniformly distributed — indistinguishable from random noise.

Encrypted: >7.5 bits ✓
